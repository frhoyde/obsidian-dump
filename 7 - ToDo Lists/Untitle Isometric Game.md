
**Engine:** Unity (3D)  
**Art:** Blender  
**Target:** Single-player, isometric combat prototype  
**Duration:** 4 Weeks (~10–12 hrs/week)

---

## 🗓️ Week 1 – Get Moving (Foundation & Feel)

**Goal:** Smooth movement + camera that feels right.

### Tasks
- [x] Set up Unity project (URP template, input system, folder structure)
- [x] Implement isometric camera (angle, follow, tilt)
- [x] Add player movement (WASD or click-to-move)
- [ ] Add acceleration/deceleration for natural feel
- [ ] Implement dash mechanic (with cooldown)
- [x] Create greybox arena (floor, walls using cubes)
- [ ] Add basic lighting + post-processing (bloom, tone mapping)
- [x] Playtest & tweak movement/camera
- [x] Record short clip for reflection

**Notes / Learnings:**
> _e.g. Camera feels too low. Dash feels snappy. Maybe reduce drag._

---

## 🗓️ Week 2 – Make It Fight (Combat Core)

**Goal:** Create the feel of impact and a basic combat loop.

### Tasks
- [x] Add basic attack (raycast or melee hitbox)
- [ ] Add visual feedback (hit flash, damage popup, sound)
- [ ] Implement one ability (e.g., shockwave or dash strike)
- [ ] Add cooldown + resource system (energy/stamina)
- [ ] Create enemy dummy (chase + simple attack)
- [ ] Add player/enemy health systems
- [ ] Add feedback: particle sparks, camera shake, sound FX
- [ ] Playtest ability rhythm (cooldown timing, power)
- [ ] Record short combat test clip

**Notes / Learnings:**
> _e.g. Enemy feels too fast. Ability range too long. Impact feels solid though._

---

## 🗓️ Week 3 – Give It Life (Arena & Assets)

**Goal:** Replace placeholders with atmosphere and style.

### Tasks
- [ ] Model placeholder player (simple bio-enhanced human)
- [ ] Model 3–4 props (barrels, consoles, vents)
- [ ] Import Blender assets into Unity + assign materials
- [ ] Add lighting polish (directional + emissive props)
- [ ] Add sound FX (attack, dash, enemy hit)
- [ ] Tweak post-processing for visual tone
- [ ] Add HP bars and minimal UI elements
- [ ] Polish hitsparks or VFX trails
- [ ] Record short visual pass clip

**Notes / Learnings:**
> _e.g. Environment readability improved. Add rim light for character._

---

## 🗓️ Week 4 – Prove It’s Fun (Playtest & Polish)

**Goal:** Tighten feedback loop, tweak pacing, and share.

### Tasks
- [ ] Add hitstop or impact pause for strong attacks
- [ ] Adjust movement + attack speeds for smoother flow
- [ ] Add enemy death effect (animation/dissolve)
- [ ] Tune AI timing, range, and damage
- [ ] Finalize basic UI (health, cooldown icons)
- [ ] Polish sound mix (attack vs ambient)
- [ ] Conduct playtest & take notes
- [ ] Export playable build
- [ ] Record short showcase trailer (15–30s)

**Notes / Learnings:**
> _e.g. Combat loop is working! Needs more variety, but feels promising._
